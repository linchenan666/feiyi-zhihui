# 沉浸演绎 · 权威视频放置说明

沉浸页（`#/immerse`）支持三种影像来源，按数据**自动选择**；任何一项没有视频，都会**自动回退到水墨图＋文字演绎**，答辩演示绝不会黑屏。

> **当前状态（已配置）**：15 项招牌均已填入 B 站**官方 / 权威片源**的嵌入地址（河南省非物质文化遗产电视专题片、官媒纪录片、省级传承保护中心演出等），联网时进入即**静音自动播放**；断网或 B 站不可达时自动回退水墨图。片源见 `data.js` 各项目的 `embed` 字段。
>
> **来源优先级**：`embed`（官方嵌入）＞ `video`（在线 mp4）＞ `HALL_VIDEOS`（本地 mp4）＞ 水墨图。若希望本地 mp4 在联网时也优先于嵌入，删除对应项目的 `embed` 字段即可。

## 一、视频文件怎么放（本地视频）

1. 把视频放进本目录 `assets/video/`，**用非遗项目的 id 命名**，例如 `junci.mp4`。
2. 格式优先 **mp4（H.264 视频 + AAC 音频）**，兼容性最好；也支持 webm。
3. 放好后运行项目根目录的 `scan_videos.py`（双击或 `python scan_videos.py`），它会扫描本目录并自动登记到 `data.js` 的 `HALL_VIDEOS`；刷新页面即生效。
4. 也可跳过扫描，直接在 `data.js` 末尾的 `HALL_VIDEOS` 里手工登记：
   `"junci": "assets/video/junci.mp4"`

> 建议单个视频控制在 30–90 秒、720p/1080p、文件 20MB 以内，加载快、切换顺。

## 二、权威、合规的来源（重要，避免侵权）

赛事明确规定：**作品侵权（含直接搬运受版权保护的整片）将取消成绩**。请通过以下合规途径获取：

- **官方嵌入（最省事、零分发风险，推荐）**：在 B 站 / 央视频 / 文旅部门官方账号打开视频 →「分享 → 嵌入代码」→ 复制其中 `src="…"` 的网址 → 填到 `data.js` 对应项目的 `embed` 字段。作品通过官方播放器在线播放，不下载、不分发视频文件。需联网，断网自动回退水墨图。
- **官方公开、可下载的宣传片 / 纪录片片段**：来自文旅厅、非遗保护单位、博物馆等官方渠道且明确允许传播的，下载后按 id 命名放入本目录。
- **自己拍摄 / 学校与文旅单位合作授权**：版权最干净，可离线播放；如有授权书请一并留存，答辩可出示。
- 请勿直接搬运爱奇艺、优酷、腾讯视频等商业平台的付费整片，或视觉中国、光厂等**未购买授权**的素材。

## 三、在线 mp4 直链（可选）

若有可公开访问、版权清晰的 mp4 直链（https 开头、可直接播放），填到 `data.js` 对应项目的 `video` 字段即可，无需下载到本地。
