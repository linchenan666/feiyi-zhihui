## 一、项目解决什么问题

**痛点**：非遗知识散落在官方名录、地方志与短视频里——难查、看不懂、没兴趣，大众缺少一个"能问、能玩、能关联"的数字入口。

**产品闭环**：被美打动 → 选中一项非遗读进去 → 与 AI 对话深挖 → 收藏 → 生成文创海报分享。

**真实数据**：15 项招牌非遗（覆盖 6 大门类、10 个地市），每项含要点、深挖方向、待核清单与知识库问答；内容基于国家级非遗名录与公开资料核对。

## 三、10 分钟极速复现指南

### 3.0 最快路径（单文件版，30 秒跑起来）

```bash
# 推荐：直接双击「非遗智汇·多彩面板版.html」
# 全部 JS / 数据 / 图片内联，零网络依赖，断网也能完整演示
```

### 3.1 环境要求

| 项 | 要求 |
|----|------|
| 操作系统 | Windows / macOS / Linux 任一 |
| 浏览器 | Chrome / Edge 114+（推荐最新版） |
| 网络 | 源码版首次打开需联网加载字体；断网自动降级（功能完整） |

**无任何构建步骤、无 Node 依赖、无包管理器。**

### 3.2 运行

```bash
# 方式一：直接双击
双击 index.html          # 源码版（多文件，依赖同目录 assets/ data.js app.js）
双击 非遗智汇·多彩面板版.html  # 单文件版（全内联，推荐演示用）

# 方式二：本地服务（可选，便于浏览器安全策略更宽松）
python -m http.server 8000
# 访问 http://localhost:8000
```

> 单文件版由 `_shots/ambient/bundle_single.py` 合成（内联 data.js→map-data.js→regions-data.js→app.js 并去除 Lenis CDN），源码改动后重新合成即可保持同步。

### 3.3 依赖清单（CDN，均为只读、无追踪）

| 资源 | 来源 | 用途 | 失败兜底 |
|------|------|------|----------|
| Noto Serif SC / Noto Sans SC | miaoda.feishu.cn 自托管镜像 | 字体 | 系统字体栈 |

> Lenis 平滑滚动库已从运行时禁用（保持原生滚动，滚轮性能最优），单文件版已完全移除。除字体外，页面**不引入任何第三方脚本、不发任何网络请求**——这是"零上传"隐私卖点的根基。

### 3.4 环境变量模板（可选，接入真·大模型）

双层架构：无 key 时内置知识库离线作答（支持多轮指代追问）；填入密钥即点亮真·大模型回答。

```js
// app.js 顶部 REMOTE_API 配置位
var REMOTE_API = {
  enabled: false,        // 置 true 启用远程大模型
  url: "",               // 例如 https://ark.cn-beijing.volces.com/api/v3/chat/completions
  key: "",               // API Key（请勿提交到公开仓库）
  model: ""              // 例如 doubao-seed-1-6-250615
};
```

> 注意：`file://` 协议下 `fetch` 会被浏览器拦截，接入远程 API 时请用 `python -m http.server` 起本地服务。

## 六、技术要点（供评审速览）

- **架构**：数据与视图严格分离（`data.js` / `map-data.js` / `regions-data.js` 纯数据，`app.js` 纯逻辑，`index.html` 纯结构与样式），hash 路由驱动 8 视图，无框架无构建。
- **双层问答架构**：本地知识库关键词打分匹配（离线可用、演示不断线）+ **多轮上下文指代消解**（「它 / 这个 / 那」自动回指上一主题）+ 远程大模型 API 预留位（有 key 即升级）。
- **图谱**：力导向布局 + 六门类扇区化 + 氛围画布（纸纹 / 晕染 / 水印）+ 节点分批入场动画 + 缩放控件（1x–3.2x 窄屏可读）。
- **地图**：写实河南 SVG 轮廓 + 10 地市标点 + 放大模态交互 + 悬浮聚焦单显 + 省份轮廓选中态 + 城市介绍。
- **安全**：全部用户内容经 `esc()` 转义防 XSS；零第三方脚本（除字体 CDN）；localStorage 读写全部 try/catch。
- **性能**：指针动效单监听 + rAF 节流；合成层 hover 才开；隐藏视图定时器即切即停；Lenis 已禁用回退原生滚动。
- **无障碍**：键盘可达（地图标点 / 图谱节点 / 收藏按钮）、`prefers-reduced-motion` 全量兜底（入场动画跳过）、语义化标签 + aria。
